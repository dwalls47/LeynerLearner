# Hebrew text: Miqra according to the Masorah (MAM)

The Hebrew Torah text in this folder is from **Miqra according to the Masorah**, prepared by
Seth (Avi) Kadish from materials he developed at Hebrew Wikisource, with technical assistance
from Erel Segal-Halevi and Benjamin Denckla.

- Source: <https://github.com/bdenckla/MAM-basics> (`MAM-simple`), commit `202e69e8e063438b5faca0d73d20a5cde3d4fb61`

- Attribution: Hebrew Wikisource,
  [Miqra according to the Masorah](https://en.wikisource.org/wiki/User:Dovi/Miqra_according_to_the_Masorah#beginning)

Files are unmodified copies of MAM-simple JSON. The versification of each was chosen so that
verse numbers match Hebcal's aliyah and haftarah references:

| File | MAM-simple folder |
|---|---|
| `Gen.json`, `Lev.json` | `json-vtrad-mam` (identical in all three versifications) |
| `Exod.json`, `Deut.json` | `json-vtrad-sef` |
| `Num.json` | `json-vtrad-bhs` |
| `Judg.json`, `1Kgs-2Kgs.json`, `Isa.json`, `Ezek.json`, `Hos-Mal.json` | `json-vtrad-mam` (identical in all three versifications) |
| `Josh.json`, `1Sam-2Sam.json`, `Jer.json` | `json-vtrad-bhs` |

(1 Samuel 25 has 44 verses here and 43 in Hebcal's verse-count table; no reading uses that chapter.)

## Sounded shevas (`sheva-na.json`)

Which shevas are sounded (sheva na), for the "Sounded sheva" option. Derived from **Phonetic MAM**
(MAM-basics `Phonetic-MAM/data/`, same commit; CC BY-SA 4.0; its attribution also names
[Al-Hatorah Mikraot Gedolot](https://mg.alhatorah.org)), whose transcriptions write a sounded sheva as a
superscript e (the Sephardic and Ashkenazic transcriptions agree on every sheva). Generated by
`Tools\ShevaNaGenerator` from the copy of Phonetic MAM bundled in `Data\PhoneticMAM` (see `SOURCE.md` there),
aligning each transcribed word with the word in this text and each sounded syllable with its sheva.

Format: `{ "Gen": { "1:1": "0.0 5.0", ... } }` — for each verse, `word.sheva` pairs: the word's index (words
split at spaces, maqaf-joined words kept together, paragraph markers and paseq skipped) and the sheva's index
within the word. A key ending in `^` is for the upper cantillation (Ten Commandments, Gen 35:22).

Coverage (Torah and Prophets): 105,779 shevas — 54,990 sounded, 45,792 silent. Unmarked: 4,973 in the divine
name (Phonetic MAM transcribes it as read, אֲדֹנָי) and 24 others. Judgments are Phonetic MAM's; for example it
treats the sheva after an initial וּ as silent (וּבְלֶכְתְּךָ = uv·lekh·tᵉ·kha), where some grammars differ.
