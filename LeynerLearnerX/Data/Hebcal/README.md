# Reading schedules from Hebcal

These files are unmodified data from Hebcal (https://www.hebcal.com), BSD-2-Clause licensed:

| File | Package | Contents |
|---|---|---|
| `triennial.json` | @hebcal/triennial 6.4.0 | Triennial-cycle aliyot for every parashah |
| `triennial-haft.json` | @hebcal/triennial 6.4.0 | Alternative triennial haftarot, by parashah and cycle year |
| `tri-haft-holidays.json` | @hebcal/triennial 6.4.0 | Alternative triennial haftarot for holidays |
| `aliyot.json` | @hebcal/leyning 10.1.0 | Full-kriyah aliyot and haftarot (Ashkenazi, Sephardi, Chabad) by parashah |
| `holiday-readings.json` | @hebcal/leyning 10.1.0 | Holiday, fast-day, Rosh Chodesh and special-Shabbat readings and haftarot |
